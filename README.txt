# سایت صیغه حلال ازدواج موقت
فایل اصلی سایت: index.html
تصویر مرجع/قهرمان: hero-reference.jpg

برای GitHub Pages:
1. هر دو فایل را در ریشه Repository آپلود کنید.
2. Settings > Pages را باز کنید.
3. Source را روی Deploy from a branch بگذارید.
4. Branch را روی main و Folder را روی / (root) قرار دهید.
5. Save را بزنید.
